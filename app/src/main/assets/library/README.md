# المكتبة العلمية

1. ضيف الصورة هنا (JPG أو PNG)، بأعلى دقة متاحة (من 2000 بكسل فأكثر بيطلع أوضح).
2. عدّل `library.json` وضيف عنصر لكل صورة:

```json
[
  { "title": "خريطة العالم", "file": "world_map.jpg" },
  { "title": "خلية حيوانية", "file": "animal_cell.png" }
]
```

- `title`: الاسم اللي هيظهر في القايمة.
- `file`: اسم الصورة بالظبط (لازم تكون في نفس الفولدر).

بعدها من السبورة اضغط **مكتبة علمية** واختار الصورة، وهتتحط كخلفية للصفحة.
